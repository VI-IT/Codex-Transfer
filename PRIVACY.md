# Privacy / Datenschutz

## English

Codex Transfer by VI-IT is a local Windows application. It uses no analytics, advertising, tracking or VI-IT cloud service.

Backup and restore operations read only the folders selected by the user and write their contents to or restore them from a local `.codex` backup file. Backup contents are not uploaded to VI-IT, OpenAI, GitHub or another server. The archive may contain private conversations, source code, local paths, SSH keys and authentication material such as `auth.json`. Keep every backup private. A strong password is recommended.

The application makes a short HTTPS request to the public GitHub Releases API when it starts in order to check whether a newer version is available. This request contains no backup contents. Network connections can also occur when the user explicitly opens the VI-IT website, GitHub, Ko-fi, PayPal or an email link.

The public executable contains no developer accounts, user accounts, passwords, cookies, sessions, private projects or access tokens. VI-IT does not receive the data processed by Codex Transfer.

## Deutsch

Codex Transfer by VI-IT ist eine lokale Windows-Anwendung. Sie verwendet keine Analysefunktionen, Werbung, Nachverfolgung oder VI-IT-Cloud.

Bei Sicherung und Wiederherstellung liest das Programm ausschließlich die vom Nutzer ausgewählten Ordner und schreibt deren Inhalte in eine lokale `.codex`-Sicherungsdatei beziehungsweise stellt sie daraus wieder her. Sicherungsinhalte werden weder an VI-IT noch an OpenAI, GitHub oder andere Server übertragen. Das Archiv kann private Unterhaltungen, Quellcode, lokale Pfade, SSH-Schlüssel und Authentifizierungsdaten wie `auth.json` enthalten. Bewahre jede Sicherung vertraulich auf. Ein starkes Passwort wird empfohlen.

Beim Programmstart erfolgt eine kurze HTTPS-Anfrage an die öffentliche GitHub-Releases-API, um auf eine neuere Version zu prüfen. Diese Anfrage enthält keine Sicherungsinhalte. Weitere Netzwerkverbindungen entstehen nur, wenn der Nutzer ausdrücklich die VI-IT-Website, GitHub, Ko-fi, PayPal oder einen E-Mail-Link öffnet.

Die öffentliche EXE enthält keine Entwicklerkonten, Benutzerkonten, Passwörter, Cookies, Sitzungen, privaten Projekte oder Zugriffstoken. VI-IT erhält die von Codex Transfer verarbeiteten Daten nicht.
