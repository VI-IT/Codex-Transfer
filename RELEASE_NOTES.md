# Codex Transfer by VI-IT 1.0.0

## English

First public release of the portable Windows migration tool for a local Codex workspace.

- Back up the complete local Codex home, settings, chats, skills, plugins and file-based authentication data
- Include selected project folders and optionally SSH keys, Git configuration and experimental Windows app data
- Restore to another Windows profile with automatic user-path mapping
- Store everything in one `.codex` archive with optional password protection
- German interface on German Windows and English on other display languages
- Local processing with no analytics or VI-IT cloud service
- Check GitHub Releases at startup and notify when a newer version is available

## Deutsch

Erste öffentliche Version des portablen Windows-Umzugstools für einen lokalen Codex-Arbeitsplatz.

- Kompletten lokalen Codex-Stand mit Einstellungen, Chats, Skills, Plugins und dateibasierten Authentifizierungsdaten sichern
- Ausgewählte Projektordner sowie optional SSH-Schlüssel, Git-Konfiguration und experimentelle Windows-Appdaten aufnehmen
- Auf einem anderen Windows-Profil mit automatischer Benutzerpfadanpassung wiederherstellen
- Alles in einer `.codex`-Datei mit optionalem Passwortschutz speichern
- Deutsche Oberfläche unter deutschem Windows, sonst Englisch
- Lokale Verarbeitung ohne Analysefunktionen oder VI-IT-Cloud
- Beim Start auf GitHub Releases nach neueren Versionen suchen und einen Hinweis anzeigen
